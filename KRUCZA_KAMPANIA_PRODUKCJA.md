# 02. ASSET BIBLE

## Assety bazowe kampanii — do przygotowania raz, używane wielokrotnie

### KRUKI
- 5 sylwetek kruka (czarny na przezroczystym tle, różne pozy): siedzący, lecący, lądujący, z głową odwróconą, z piórem w dziobie
- Format: PNG z alfa, min. 2000px
- Styl: realistyczna sylwetka, nie kreskówkowa
- Źródło: Midjourney prompt lub Unsplash (filtr "raven silhouette CC0")

**Midjourney prompt bazowy:**
```
raven silhouette, black on transparent background, 
realistic, dark nordic aesthetic, gothic, 
sharp feathers detail, PNG --ar 1:1 --style raw
```

### PIÓRA
- 10 piór (różne kąty i pozycje)
- Format: PNG z alfa
- Użycie: teasery, backgrounds, ukryte elementy

### PIECZĘCIE
- Pieczęć TMD (główna) — okrągła, łacińska/nordycka typografia, symbol kruka
- Pieczęcie 4 Zakonów — osobne dla każdego
- Format: SVG + PNG
- Styl: Woskowa pieczęć, nie wektorowa naklejka

### PERGAMINY
- 5 tekstur pergaminu (jasne, ciemne, postarzałe, rozdarte, ze śladami wosku)
- Format: JPG 3000×4000px lub PNG
- Użycie: Akta, dokumenty, listy

### KAMIEŃ
- 5 tekstur kamienia (granit, śnieg na kamieniu, mech na kamieniu, mokry kamień, wykuta runa)
- Format: JPG 3000×3000px
- Użycie: Tła, separatory, narracyjne elementy

### RUNY
- Pełny alfabet Runów Północy (26 symboli + cyfry)
- Format: SVG (każda runa osobno) + PNG sprite sheet
- Styl: Autorski, nie identyczny z Elder Futhark, ale inspirowany
- Użycie: szyfry, dekoracje, grafiki, ARG

### HERBY ZAKONÓW
- Herb Ravnheim — kruk, gwiazda, czerń/fiolet/srebro
- Herb Reinhall — renifer/poroże, krew, bordo/złoto
- Herb Björnhall — niedźwiedź/pazury, żelazo, grafit/czerwień
- Herb Otergard — wydra/fiolki, petrol/zieleń
- Format: SVG (skalowalne) + PNG 2000×2000px
- Wersje: kolorowa, monochromatyczna (biała), monochromatyczna (czarna)

### TWIERDZA
- Min. 3 widoki Twierdzy: panorama, brama, wieża
- Format: JPG 4000px+ (landscape)
- Styl: Fotorealistyczny lub painterly, nie low-poly
- Źródło: Midjourney

**Midjourney prompt bazowy — Twierdza:**
```
ancient nordic stone fortress, scandinavia, 
dark mountains, snow, night, fog, 
dramatic lighting from inside windows, 
cinematic, photorealistic, 8k, 
no people, gothic architecture --ar 16:9 --style raw
```

### WNĘTRZA
- Biblioteka (nocna, księżyc przez okno)
- Sala Czarnej Magii (ciemna, świece, runy na ścianach)
- Brama (wewnętrzna perspektywa)
- Wielka Sala (zimna, monumentalna)
- Format: JPG 3000px+ landscape

### ŚNIEG, MGŁA, EFEKTY
- Overlay śniegu: 5 wariantów (gęsty, lekki, z boku, z góry, zawieja)
- Overlay mgły: 3 warianty
- Format: PNG z alfa, 3000×3000px

# 04. TYPOGRAFIA

## Rekomendacje fontów

### DISPLAY (nagłówki, nazwa Twierdzy)
**Rekomendacja:** Cinzel (Google Fonts)
- Klasyczny, dignified, łacińskie korzenie
- Działa z polskimi znakami (częściowo — wymaga testu)
- Alternatywa: IM Fell English (Google Fonts) — bardziej historyczny
- Użycie: TWIERDZA MAGII DURMSTRANG, tytuły Zakonów, nagłówki sekcji

**Canva alternatywa:** "Old Standard TT" lub "Cormorant Garamond"

### SERIF (tekst długi, dokumenty, lore)
**Rekomendacja:** Lora (Google Fonts)
- Czytalna, elegancka, działa z polskimi znakami
- Dobra na ciemnym tle przy jasnym kolorze
- Alternatywa: EB Garamond

**Użycie:** Treści Akt, listy, opisy Zakonów, dłuższe posty

### SANS / UI (nawigacja, UI, copy social)
**Rekomendacja:** Inter (Google Fonts)
- Czytelność na ekranie: doskonała
- Minimalistyczna, nie fantasy
- Używać wyłącznie dla małego tekstu i UI
- Alternatywa: DM Sans

### RUNES / ACCENT (Kruczy Szyfr, dekoracje)
**Rekomendacja:** Elder Futhark font (DaFont.com — darmowy)
Lub: autorski font (stworzyć własny na Calligraphr.com — darmowy do 75 znaków)

**Użycie:** Szyfrowane wiadomości, dekoracyjne napisy, runiczne elementy

# 07. TUTORIAL KROK PO KROKU: TEASER 01 — PIÓRO NA ŚNIEGU

**Program:** Photopea
**Format:** 1080×1350px
**Czas produkcji:** 30–60 minut
**Wynik:** Pierwsze zdjęcie kampanii — pióro na śniegu

### Assety potrzebne:
- Zdjęcie śniegu (białe, czyste) — Unsplash: "white snow texture"
- PNG pióra czarnego (z przezroczystym tłem) — Unsplash lub generowane

### Kroki:

**KROK 1:** Nowy dokument 1080×1350px, RGB, 72 DPI

**KROK 2:** Wgraj zdjęcie śniegu jako warstwę tła. Ustaw tak, żeby wypełniało cały kanvas.

**KROK 3:** Dodaj Adjustment Layer → Curves. Lekko przyciemnij środek (nie czerń całkowicie). Efekt: śnieg jest brudnobiały, nie czysty — bardziej klimatyczny.

**KROK 4:** Dodaj Adjustment Layer → Color Balance → Shadows: przesuń w stronę chłodnych tonów (Cyan +10, Blue +15). Efekt: zimna, nordycka atmosfera.

**KROK 5:** Wgraj PNG pióra. Ustaw centralnie lub lekko poniżej centrum. Ustaw rozmiar tak, żeby pióro zajmowało ~30% wysokości kadru.

**KROK 6:** Na warstwie pióra dodaj Layer Style → Drop Shadow:
- Opacity: 40%
- Angle: 120°
- Distance: 8px
- Spread: 0%
- Size: 20px
- Color: bardzo ciemny niebieski (#1A1A2E)

**KROK 7:** Nowa warstwa POWYŻEJ wszystkiego — "Vignette".
- Wypełnij czernią (#000000)
- Zmień Blend Mode: Multiply
- Opacity: 0%
- Zastosuj Filter → Lens Correction → Vignette: Amount -40, Midpoint 50
- LUB ręcznie: zaznaczenie eliptyczne środka, Inverse, Feather 200px, Delete. Zmień opacity na 40%.

**KROK 8:** Nowa warstwa — "Noise / Grain":
- Wypełnij szarością 50% (#808080)
- Blend Mode: Overlay
- Filter → Noise → Add Noise: Amount 3–5%, Gaussian, Monochromatic
- Opacity: 60%
Efekt: ziarno filmowe — klimat starej fotografii.

**KROK 9:** Nowa warstwa — "Snow Overlay":
- Jeśli masz PNG z padającym śniegiem — dodaj i ustaw Blend Mode: Screen
- Jeśli nie: na czarnej warstwie zastosuj Filter → Render → Clouds + przemień w cząsteczki przez Levels/Threshold (zaawansowane)
- Opacity: 20–30%

**KROK 10:** Dodaj tekst (opcjonalne w tym teaserze):
- Tylko jedna runa lub w ogóle brak tekstu
- Font: Elder Futhark, rozmiar 18–24px, kolor #C4C8D4 (srebro)
- Pozycja: lewy dolny róg lub prawy górny

**KROK 11:** Finalna korekta:
- Adjustment Layer → Levels: upewnij się że czernie są głębokie
- Adjustment Layer → Vibrance: -10 (lekkie przygaszenie)

**KROK 12:** Export:
- File → Export As → JPEG, Quality 90%
- LUB WebP, Quality 85%
- Nazwa: TMD_TEASER_PIERO_SNIEG_01_1080x1350_v01.jpg

# 08. TUTORIAL: AKTA CZARNEJ MAGII — GRAFIKA DOKUMENTU

**Program:** Photopea
**Format:** 1080×1350px
**Czas produkcji:** 1.5–3h
**Wynik:** Dokument "Akta Czarnej Magii" wyglądający jak zastrzeżony plik Twierdzy

### Assety:
- Tekstura pergaminu (Unsplash: "old paper texture")
- Tekstura kamienia lub ciemnego drewna (tło)
- Font: Cinzel Decorative (nagłówek) + Lora (tekst) + Elder Futhark (runy)
- Pieczęć TMD (przygotowana wcześniej)
- Tekstura czarnego tuszu / plama (Unsplash: "ink splash transparent")

### Warstwy (od dołu do góry):

```
LAYER 01: BACKGROUND_STONE
LAYER 02: VIGNETTE
LAYER 03: PAPER_TEXTURE
LAYER 04: PAPER_SHADOW (cień dokumentu)
LAYER 05: PAPER_AGING (dodatkowe starzenie)
LAYER 06: DOCUMENT_BORDER
LAYER 07: HEADER
LAYER 08: STAMP_ZASTRZEŻONE
LAYER 09: BODY_TEXT (właściwa treść)
LAYER 10: REDACTION_BARS (czarne paski cenzury)
LAYER 11: RUNE (ukryta)
LAYER 12: HANDWRITING (notatka marginalna)
LAYER 13: NOISE_GRAIN
LAYER 14: COLOR_GRADE
```

### Kroki:

**KROK 1:** Nowy dokument 1080×1350px

**KROK 2 — BACKGROUND_STONE:**
Wgraj teksturę kamienia lub ciemnego drewna. Ustaw jako tło. Przyciemnij (Curves: shadows w dół).
Blend Mode: Normal, Opacity: 100%

**KROK 3 — VIGNETTE:**
Ciemna winieta krawędzi — technika jak w teaserze, ale mocniejsza (Opacity 60%).

**KROK 4 — PAPER_TEXTURE:**
Wgraj pergamin. Skaluj do ~80% szerokości kanvas (żeby wyglądał jak kartka leżąca na stole).
Ustaw lekkie obrócenie (-2°) dla naturalności.
Add Layer Mask i delikatnie wymaskuj narożniki.
Blend Mode: Normal, Opacity: 95%

**KROK 5 — PAPER_SHADOW:**
Zduplikuj warstwę pergaminu. Przesuń o 10px w prawo i 10px w dół.
Wymaż treść (wszystko czarne), tylko cień.
Blend Mode: Multiply, Opacity: 40%
Filter → Blur → Gaussian Blur: 15px

**KROK 6 — PAPER_AGING:**
Nowa warstwa powyżej pergaminu.
Brush Tool: miękki pędzel, ciemnobrązowy (#3D2010), Opacity 20%
Maluj delikatnie na krawędziach pergaminu (naturalny "brudersztyk")
Blend Mode: Multiply

**KROK 7 — DOCUMENT_BORDER:**
Rectangle Tool — cienka ramka (2–3px) wokół "obszaru dokumentu".
Kolor: #B8963C (stare złoto)
Opacity: 50–70%

**KROK 8 — HEADER:**
Text Tool → Cinzel, 24–28px, #2A0810 (ciemne bordo) lub #1A1A22 (grafit)

```
────────────────────────────────
TWIERDZA MAGII DURMSTRANG
KATEDRA CZARNEJ MAGII
DOKUMENT ZASTRZEŻONY — KLASA III
────────────────────────────────
```

**KROK 9 — STAMP_ZASTRZEŻONE:**
Utwórz lub wgraj pieczęć "ZASTRZEŻONE".
Możesz stworzyć ją ręcznie:
- Elipsa (stroke czerwona lub bordowa, no fill)
- Tekst w środku: "DOSTĘP OGRANICZONY" lub "ZASTRZEŻONE"
- Font: Cinzel wszystkimi capsami
- Obróć o 30–45°
- Blend Mode: Multiply, Opacity: 70%

**KROK 10 — BODY_TEXT:**
Wpisz treść dokumentu — Lora 12–14px, ciemny kolor (#1E1810).

Przykładowa treść:
```
AKTA CZARNEJ MAGII — SERIA I

TEMAT: Klątwy Wiążące — podstawy kontroli

Klątwa wiążąca jest jedną z najbardziej
zaawansowanych form Czarnej Magii.
W odróżnieniu od klątek prostych, nie
uderza bezpośrednio — ogranicza.

§ 1. Definicja
Klątwa wiążąca [OCENZUROWANE] poprzez
stworzenie magicznego [OCENZUROWANE]...

§ 2. Zastosowania
Lista zastosowań zatwierdzonych przez
Kanclerza: [PATRZ ZAŁĄCZNIK III]
[OCENZUROWANE]

UWAGA: Praktyczne ćwiczenia klątek
wymagają obecności wykwalifikowanego
Profesora i pisemnej zgody [OCENZUROWANE]
```

**KROK 11 — REDACTION_BARS:**
Rectangle Tool — czarne prostokąty (#0A0A0C) nad wybranymi fragmentami tekstu.
Lekki cień (Drop Shadow 10px, czarny, 50%).
Niektóre paski lekko ukośne (realistyczność).

**KROK 12 — RUNE:**
Dodaj jedną runę w prawym dolnym rogu dokumentu.
Font: Elder Futhark, bardzo mały (8–10px) lub duży ale bardzo niewidoczny.
Kolor: ciemnobrązowy, Opacity: 20–30%
Efekt: ukryta runa — ARG element.

**KROK 13 — HANDWRITING:**
Text Tool → Font ręczny (np. "Caveat" z Google Fonts — imitacja odręczności).
Kolor: ciemnoniebieski (#1A1A4A) lub ciemnoczerwony (#4A0E1A)
Treść notatki marginalnej: "nie rób tego bez Profesora. serio."
Obróć o -15° (naturalność).

**KROK 14 — NOISE_GRAIN:**
Jak w poprzednim tutorialu — ziarno filmowe. Opacity: 40%

**KROK 15 — COLOR_GRADE:**
Adjustment Layer → Photo Filter → Sepia lub Warming: 10%
Adjustment Layer → Curves → lekkie ochłodzenie cieni

**KROK 16 — Export:**
JPEG 90% lub WEBP 85%
Nazwa: TMD_AKTA_CZERNAMAGIA_001_1080x1350_v01.jpg

# 10. DAVINCI RESOLVE WORKFLOW

## Wersja darmowa — DaVinci Resolve 18/19

Darmowa wersja wystarczy do:
- Edycji video do 30s
- Color grading
- Basic motion graphics
